# Demostración · Página de gestión para La Petit Atelier

Demostración de una página de gestión para pastelerías artesanales, desarrollada por
**Wydan Solutions**: agenda de pedidos con seña y saldo, presupuestos, clientes con mensajes
de WhatsApp listos, recetas que calculan su costo solas con los precios del mercado, paso a paso
con modo cocina, stock, producción del día, control mensual y anual, y exportación a PDF y Excel.

- **Todos los datos son inventados.** No hay información real de ninguna persona.
- Funciona por completo en el navegador: no hay servidor ni base de datos.
- Contraseña de la demostración: `1234`.
- Fotos de las recetas: [Unsplash](https://unsplash.com) (licencia libre).

Cada persona que abre la página trabaja con su propia copia de los datos de ejemplo,
guardada solo en su navegador.
